Class Definition: timeseries

datatypes: timeseries

Array of samples indexed by time.

A timeseries object holds a sequence of samples, each taken at a time on a common time vector, together with the metadata that describes them: the units of the data and of the time, an optional absolute start date, the method of evaluating the series between samples, a quality code per sample, and named events.

Each sample may be a scalar, a vector, or an array. The time vector runs either down the first dimension of the data, each row being a sample, or along its last dimension, each slice being one; IsTimeFirst reports which, as the constructor describes.

timeseries is a value class: every method returns a modified copy and leaves its input unchanged. An array of timeseries objects is built by concatenation, as [ts1, ts2].

MATLAB recommends timetable for new code; timeseries is provided for code that exchanges it.

Property names are case-sensitive in dot indexing, as for every other class; MATLAB also reads ts.name for ts.Name. get and set accept any case.

See also: tscollection, timeseries2timetable, timetable, tsdata.timemetadata, tsdata.datametadata, tsdata.qualmetadata, tsdata.event, tsdata.interpolation

Source Code: timeseries

The timeseries class contains the following properties:

A vector of tsdata.event objects, or [] when there are none, by default.

A character vector, 'unnamed' by default, and '' for a series created with no argument. A string scalar is converted; any other value is refused, where MATLAB accepts it.

A numeric or logical array of any class, holding one sample per time and read against the time vector as the constructor describes: rows, or slices along the last dimension, with a matrix of as many columns as there are times stored as an Rx1xN array. Any other number of samples than there are times is refused, except while one of the two is empty, which lets a series be built by assigning Time and Data in turn.

A column vector of finite, non-decreasing times, in ts.TimeInfo.Units, counted from ts.TimeInfo.StartDate when that is set. Repeated times are allowed. An unsorted time vector is refused on assignment, since sorting it would move samples it was not given with. It is stored as double: MATLAB keeps an integer class, and then rounds new times to it.

Integers from -128 to 127, stored as double, [] by default. Either one code per sample, as a vector, or one per data element, as an array the size of Data. Their meaning is listed in QualityInfo.

true when each row of the data is a sample, false when the time vector runs along the last dimension of the data, as the constructor describes. It is kept when samples are selected, so a three-dimensional series cut to one sample holds a matrix with IsTimeFirst still false. Assigning the value it already has is accepted, and assigning the other is refused, since it would misalign the data with the time vector.

A logical scalar, true by default; 0 and 1 are converted.
